1. Difference between synchronous and asynchronous file operations:
Synchronous file operations block the execution of the program until the operation completes, whereas asynchronous file operations do not block execution and allow other tasks to run while the operation is being completed.

2. When should you use file streams instead of reading the entire file?
File streams should be used when working with large files because they read data in chunks, which improves performance and reduces memory usage.

3. Purpose of the ‘utf8’ encoding parameter in file operations:
The ‘utf8’ encoding parameter tells Node.js to interpret the file content as UTF-8 encoded text, allowing it to be read as human-readable strings instead of raw binary data.

4. Common error codes in file system operations:
ENOENT – File or directory not found
EACCES – Permission denied
EISDIR – Is a directory
ENOTDIR – Not a directory

5. How would you safely delete a directory with all its contents?
By using fs.rm() with recursive and force options.

6. Concept of piping in streams:
Piping transfers data from one stream to another, for example copying data from a readable stream to a writable stream.

7. Importance of handling errors in file operations:
It prevents application crashes and ensures reliable program execution.

8. Difference between writeFile and appendFile:
writeFile overwrites content, while appendFile adds content to the end of the file.
